# بازسازی برنامه اندروید

این مخزن اسکلت عمومی یک برنامه React Native برای شروع بازسازی APK ارسالی است.

## وضعیت

- APK بررسی‌شده با React Native و Hermes ساخته شده است.
- فایل APK شامل بایت‌کد کامپایل‌شده است، نه سورس اصلی JavaScript؛ بنابراین این مخزن هنوز بازسازی کامل صفحه‌ها یا منطق برنامه نیست.
- APK اصلی عمداً در مخزن عمومی قرار نگرفته است.
- صفحه فعلی فقط یک پوسته فارسی و راست‌چین برای شروع توسعه است.

## اجرا

```sh
npm install
npx expo start
```

## ساخت APK

در GitHub از بخش Actions، گردش‌کار `Build Android APK` را اجرا کنید. با هر push به شاخه `main` نیز به‌صورت خودکار اجرا می‌شود. فایل APK از بخش Artifacts همان اجرا قابل دریافت است.

## امنیت

رمز، OTP، فایل امضای اندروید، کلیدهای API و اطلاعات ورود ربات را در این مخزن عمومی قرار ندهید. برای انتشار نسخه نهایی باید کلید امضای متعلق به خودتان را به‌صورت GitHub Actions Secrets تنظیم کنید.

## ادامه کار

برای بازسازی دقیق‌تر، تصاویر صفحه‌ها، شرح جریان‌های اصلی و مشخصات قابلیت‌های موردنیاز را اضافه کنید. دسترسی به سورس اصلی یا مستندات API نتیجه را دقیق‌تر می‌کند.
